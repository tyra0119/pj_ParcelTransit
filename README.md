# にもつ停留所

公共交通オープンデータチャレンジ2026 応募作。
宅配トラックを「路線バス／デマンド交通」に見立て、配達ルートを **GTFS-Flex** で表します。配達は降車、集荷は乗車にあたります。

> 時間指定をしても、いつ来るか分からず出かけられない。
> 不在で持ち戻り、再配達になる。

配達・集荷をめぐる、利用者と業者の両方の困りごとに一石を投じる試みです。

## デモ

- **利用者のアプリ**: https://tyra0119.github.io/pj_ParcelTransit/
- **業者の画面（サンプル）**: https://tyra0119.github.io/pj_ParcelTransit/carrier.html
- **マニュアル**: https://tyra0119.github.io/pj_ParcelTransit/manual.html
- **紹介動画（2 分 57 秒）**: https://www.youtube.com/watch?v=WnPI8yp2h8g

2 つの窓を並べると、利用者のアプリでの集荷の依頼や不在の連絡が、業者の画面にすぐ届きます。

業者の画面は**サンプル**です。宅配各社はすでに自社の業務システムを持っているはずなので、業者向けのアプリを提案するものではありません。デモで「業者の中で何が起きているか」を見せるために作りました。

## 何を提案するか

1. **利用者のアプリ**（にもつ停留所）: 各社の便をまとめて地図に出し、お届けQR から「あと○停留所」を計算する
2. **各社が公開層を ODPT に出す決まり**: 住所を除いた公開層を GTFS-Flex / GTFS-RT で公共交通オープンデータセンター（ODPT）に出す
3. **申し込み先の共通の形式**: 集荷の依頼・不在の連絡を、各社の申し込み先へ同じ形で送る（宛先は公開層の booking_rules に書く）

## 住所は出さない

| 層 | 誰が見る | 中身 |
| --- | --- | --- |
| 業者層 | 業者だけ | 住所、配達か集荷か、巡回順 |
| 公開層 | だれでも（ODPT） | 街区単位の停留所、巡回順、時間幅、おおまかな位置（3分遅れ）、集荷の受付と締切 |
| 本人層 | お届けQR を持つ本人 | 到着予想の時間幅、あと○停留所（アプリの手元で計算） |

- 停留所は家ではなく街区。荷物が1件だけの街区は隣とまとめる
- 配達と集荷を区別しない（乗降区分は全部「要予約」）
- 公開層は3分ごとにまとめて更新。トラックの位置は街区単位に粗くし、3分遅らせる
- お届けQR には便・停留所・期限・合言葉だけを入れ、住所は入れない

## 公開データ（GTFS-Flex）

`gtfs/` に、デモの1日分のフィードがあります（`locations.geojson` に街区の区画、`stop_times.txt` は時間幅、`booking_rules.txt` に集荷の受付）。

## データの出典

書き方は、各提供元の決まり（公共交通オープンデータセンターの FAQ「CC BY 4.0 ライセンスのデータを利用する際のクレジット」、位置参照情報ダウンロードサービスの利用約款、e-Stat の利用規約、国土地理院コンテンツ利用規約）に合わせています。

- 東京都交通局・公共交通オープンデータ協議会、東京都交通局 バス関連リアルタイム情報、クリエイティブ・コモンズ・ライセンス 表示4.0国際（https://creativecommons.org/licenses/by/4.0/deed.ja）
  - 公共交通オープンデータセンターから取得（https://ckan.odpt.org/dataset/b_bus_gtfs_rt-toei ）。公開地図の「参考: 都営バスの実際の位置」に使用
- 出典：位置参照情報ダウンロードサービス（国土交通省）（https://nlftp.mlit.go.jp/isj/）
  - 「位置参照情報ダウンロードサービス」（国土交通省）の街区レベル位置参照情報（令和5年、東京都江東区。上津台で試すときは兵庫県神戸市北区）をもとに、にもつ停留所が街区の区画を作成
- 出典：政府統計の総合窓口(e-Stat)（https://www.e-stat.go.jp/）
  - 「令和2年国勢調査 小地域集計」（総務省統計局）を加工して作成（町丁目別の世帯数から、配達件数の模擬データを作成）
- 出典：国土地理院（地理院タイル 淡色地図）（https://maps.gsi.go.jp/development/ichiran.html）

配達・集荷のデータと宅配会社（A社・B社）は模擬・架空です。このアプリについて、公共交通事業者や宅配会社には問い合わせないでください。お問い合わせは GitHub の Issues（https://github.com/tyra0119/pj_ParcelTransit/issues）へ。
